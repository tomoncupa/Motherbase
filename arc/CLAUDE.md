# ARC — Mind Canvas (CLAUDE.md)

Single-file mind-mapping app for Tom (solo fitness coach, PROTAGONIST brand). Everything lives in `arc/index.html` (~4,400 lines: CSS + HTML + one inline vanilla-JS script). No build step, no dependencies beyond Google Fonts CDN. Deployed by copying the file to `tomoncupa.github.io`. Built iteratively across ~15 versions in claude.ai; this file is the handoff brief.

**ARC is a sub-project of Motherbase.** It lives at `arc/` inside the Motherbase repo. This brief governs the `arc/` folder only; the repo-root `CLAUDE.md` (Daily Quest OS / LifeOS) governs everything outside it.

**This folder is canonical.** `arc/index.html` is the file to edit and the one under git. A byte-identical convenience copy may sit at `Downloads/arc_12.html`; if the two ever disagree, this one wins.

## Working rules

- **One file.** Never split into modules unless Tom asks. Keep it deployable by copy.
- After ANY edit: extract the inline script and run `node --check` on it. The script contains the literal string `'<scr'+'ipt>'` (intentionally split — never "fix" it) so extract via first `<script>` / last `</script>` indexes.
- Verify every `$('#id')` in JS has a matching `id=` in markup after edits (past regressions came from exactly this).
- Test in a real browser when possible (Tom's daily map is ~200 nodes). Commit per feature; Tom will revert via git if a pass breaks.
- Persist user data compatibly. **IndexedDB (`arc` db, `kv` store) is authoritative**: key `db` = JSON of `{maps:[{id,title,nodes:{},links:[],view,snaps,edgeStyle,posGrad,rankColors,hideCousins}],currentId,ts}` (ts = authority timestamp); keys `hist:<mapId>` = persisted undo/redo (`{u,r}`, ~25MB budget, debounced 800ms). localStorage `arc_v1` is the migration source + best-effort mirror (only written when JSON < 3.5MB); on boot the sync localStorage copy loads first, then IDB swaps in if its `ts` is newer. Small prefs stay in localStorage: `arc_key` (API), `arc_theme` (now `{scheme:name}`), `arc_palettes` (`{scheme:{bg,panel,line,ink,mut,acc,colors[6]}}` — per-scheme colour overrides, stored only for schemes the user actually edited), `arc_typecolors`, `arc_snap`, `arc_space`, `arc_keys`, `arc_font`, `arc_bg`, `arc_declutter`, `arc_expandfit`, `arc_dashmove`, `arc_stream`, `arc_clip`. Never break old maps.
- Test fixture: `arc/arc_fixture.md` (Tom's real exported map, ~870 nodes after import) — run layout/perf changes against it via `importMarkdown(await (await fetch('arc_fixture.md')).text())`.

## Architecture (the parts that must not regress)

**Canonical hierarchy layer `H`** — the single source of parentage. `H.parents/children/roots/isAncestor/walk` union the primary `node.parentId` with relation links (`link.rel==='child'` ⇒ a is parent of b; `'parent'` ⇒ b is parent of a). Consumers: Markdown export, presentation order, focus view, cycle guards. **No subsystem may infer hierarchy on its own.** Multi-parent is real: one node, several parents; Markdown intentionally duplicates it under each parent (path-based cycle guard only — never global visited-suppression). Positions/layouts follow the *primary* parent chain only (a DAG has no tree embedding); that asymmetry is accepted and documented.

**Edge geometry** — `edgeD(a,b,style)` for everything; `linkD` defers to `M().edgeStyle` unless a per-link `style` override exists (the only allowed exception). Anchors are 4-cardinal side-centers with **super Y-bias**: vertical anchors unless |dx| > 2.5·|dy| (same threshold flips ortho elbows vertical-first). Side exits extend along outward normals — lines never route behind their parent.

**Line pattern is semantic, never manual**: equal = solid & still · cousin = faded dash & still (hidden when `M().hideCousins`, always visible in focus) · everything else (tree edges + child/parent links) = dashed + drift animation (`arc_dashmove` is the only off-switch). Connection stroke = 50/50 `blendHex` of its endpoints; hierarchical links styled `.hier` to match tree edges.

**Color doctrine** — `nodeColor` chain: position-gradient (`posGrad`, hue around centroid) → rank colors (`rankColors` + `n.rank` F–S via `RANKC`) → `lineageBase()`: **no parent is primary for color — a node's inherited color is the equal N-way blend (`blendMany`) of every `H.parents()` entry's own resolved color**, then a descendant's manual `n.color`/`type` is blended 50/50 into that inherited blend (never emancipated). Depth for lightness falloff is the max depth across all parent branches + 1. Cycle guard is a per-branch copied `seen` Set (never a shared mutable one), so diamonds — two parents sharing a common ancestor — resolve correctly instead of short-circuiting. Lightness drops ~4/depth, saturation scales with node size — **except when the resolved base is greyscale (HSL saturation < 10), which stays greyscale across the full lightness range**. Without that exemption `shadeFor`s 38% saturation floor and 32-72 lightness clamp invent a hue out of nothing (#FFFFFF rendered as #d39c9c pink), which makes a white-on-black or black-on-white scheme impossible.

**Never-overlap** — `resolveOverlaps(fixedId)` (pair separation, pinned-vs-pinned skipped unless one is fixed) runs after: layouts, drag end, resize/scale end, branch expand, RPG expand, paste. Auto-adopt requires actual bounding-box overlap between the dragged node and a candidate (largest-overlap-area wins when several qualify) — proximity alone never adopts. `n.pinned` = user placed it; fan/auto-layout never moves pinned nodes.

## Feature inventory (all must keep working)

Canvas: left-drag = marquee multi-select (Shift adds, Ctrl+click = branch select), pan = Alt/right/middle-drag, wheel zoom 0.15–2.5, pinch, minimap ≥25 nodes, coach hints fade at 6 nodes, universe starfield (toggleable, reduced-motion safe). Nodes: Tab/Enter/Ctrl+Enter create (fan placement continues parent angle, vertical default, avg-font sizing, declutter), Space/click-selected/2×click/F2 edit, rich text (B/I/U, bullet/numbered/**checklist** `[]`→☑ click-toggleable outside edit, `[title]`→quote block), description line (Alt+Enter newlines), width grip + corner scale (no limits), align, roles T/S/B, ▾ minimize card, collapse `C`, states ◐✓🔒 `D`, F–S rank badges+frame, types, star-slides `S`, speaker notes `N`. RPG (`R`): 7 levels default, pips, active/passive, ✦ AI tier generation, node-clone Skill Card export 1080×1350. Edge styles: organic / straight / ortho, chosen per map. The **hand-drawn** curve (`edgeD(a,b,'hand')` — the organic curve resampled with a deterministic endpoint-seeded wobble) is deliberately NOT in that list: it belongs to the doodle scheme and is applied by `edgeStyleNow()`, which returns `'hand'` whenever `THEME_NAME==='doodle'` and the map's own setting otherwise. Every edge-drawing path (render, `linkD`, both PNG exports) must go through `edgeStyleNow()`; an explicit per-link style override still wins over it. Connections: X = parent→child pick w/ ghost line, 16px hit halos, right-click line = label(start/mid/end)/relation/style-override/reparent/detach/convert; right-click node = ancestry path, type, rank, ⊕ add parent, ✂ orphan, ⇌ transfer. Focus `O` = **temporary** top-down tree view (positions stashed/restored except user-moved). Layouts (✳/L): radial, bilateral, tree — size-aware, spacing option, never resize nodes. Present `P` (star-filtering, notes HUD, stream mode w/ popup, per-slide edge pulses), Ctrl+K jump, markdown import, snapshots, undo (nodes+links), **schemes** (fonts/shape/texture only — every `body.theme-*` rule reads palette tokens, never a literal hex, so any scheme works in any colourway) with per-scheme editable palettes: labelled fields, hover-to-preview, return-to-default, saved separately per scheme (`applyScheme`/`setScheme`/`paletteFor`/`savePalette`/`clearPalette`), **configurable hotkeys** (`DEFKEYS/KEYS/KEYREV`, ⚙ grid, red = unassigned), instant tooltips, JSON/workspace backup, **chart-only transparent PNG export** (`exportChartPng(scope)`, scope = all / view / sel — no background, no UI chrome, faithful to the active scheme), read-only share export (`PRISTINE` + `ARC_SHARE` + `RO` guards), Claude API (keyless in claude.ai artifacts, `arc_key` self-hosted, model `claude-sonnet-4-6`).
