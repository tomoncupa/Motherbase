# MOTHERBASE: read CLAUDE.md

The brief for this repo is `CLAUDE.md`, beside this file. Read it before doing
anything here, and read `DOCTRINE.md` before building a feature. An app folder
with its own brief has a `CLAUDE.md` inside it: read that before touching the
folder too. They are written for Claude and apply to any agent working here,
Codex included.

This file used to be a copy of `CLAUDE.md`, made on 2026-09-09. A copy drifts:
by 2026-09-14 it pointed at briefs that do not exist and was missing every
decision made since. So it is a pointer instead, and there is nothing to keep
in step. Tom, 2026-09-14.

Claude sessions and Codex sessions work in this folder at the same time and
cannot see each other. The section "Working alongside other sessions" in
`CLAUDE.md` applies to both: stay in your folder, look before you write, add
files to a commit by name, and commit early.
